# Badge sources

These badges use the [Shields.io](https://shields.io/) `flat-square` style:
20px height, 14px logos, and regular 11px labels with the font stack
`Verdana, Geneva, DejaVu Sans, sans-serif`.
The SVGs are stored locally and retain accessible titles and image labels.

- Python, R, TypeScript, JavaScript, Bash, HTML, CSS, and Nextflow icon geometry: [Simple Icons](https://github.com/simple-icons/simple-icons).
- Snakemake adds the [official workflow catalog logo](https://github.com/snakemake/snakemake-workflow-catalog/blob/main/logo-snake.svg), recolored for contrast, to the same Shields.io badge layout.
- Mako uses a text label without an invented logo.

Brand names and logos belong to their respective owners.
