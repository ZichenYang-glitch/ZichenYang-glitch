# Badge sources

These compact badges use regular-weight labels with a system UI font stack.
The SVGs are self-contained; text and icons are rendered locally by the browser.

- Python, R, TypeScript, JavaScript, Bash, HTML, CSS, and Nextflow icon geometry: [Simple Icons](https://github.com/simple-icons/simple-icons).
- Snakemake icon geometry: [official Snakemake workflow catalog logo](https://github.com/snakemake/snakemake-workflow-catalog/blob/main/logo-snake.svg), recolored for contrast.
- Mako uses a text label without an invented logo.

Brand names and logos belong to their respective owners.
